# 赛博朋克地下黑客据点（Cyberpunk Hacker Dens & Cyberspace）

本技能专门针对赛博朋克深层地下世界：地下黑客工坊、暗网机房、神经接驳义体改装店、悬浮全息监视屏幕阵列与虚实交错的赛博空间（Cyberspace）。

## 场景核心视觉特征

1. **密集硬件阵列与杂乱线缆（Hardware Clutter & Server Racks）**
   - 堆叠如山的裸露主板、浸没式水冷管道、闪烁的绿色与琥珀色服务器指示灯。
   - 地面铺满蛇形盘绕的同轴线缆与光纤总线，工作台上散落电烙铁、拆解的义体手臂与半透明芯片卡。

2. **全息投影与立体数据流（Holographic Data Streams）**
   - 环绕操作者的半透明悬浮全息投影界面（Holographic HUDs），跳动着密集的反编译十六进制代码、拓扑网络图与监视摄像画面。
   - 经典绿荧荧或冰蓝色的代码微光映照在操作者专注的脸孔与反光护目镜上。

3. **幽闭隐蔽的地下冷调氛围（Claustrophobic Underground Mood）**
   - 斑驳潮湿的水泥混凝土承重墙、防空洞铁锈钢门，隐蔽通风扇投下缓慢旋转的阴影。
