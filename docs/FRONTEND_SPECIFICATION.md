## 3. 设计系统与视觉规范 (Design System Tokens)

- **设计基调**：深色影院工业级控制台 (Cinema Dark Console)。高对比度，消除视觉疲劳，精准呈现画面色彩与掩码边缘。
- **色彩规范 (Tokens)**：
  - `Surface-0 (Canvas Base)`: `#0B0F17` (深空黑，主画板底色)
  - `Surface-1 (Panel Cards)`: `#151B28` (暗蓝灰，容器背景)
  - `Surface-2 (Border/Input)`: `#1F293D` (边框与次级卡片)
  - `Accent-Primary (Action)`: `#3B82F6` (科技蓝，主要操作与激活态)
  - `Accent-Gold (Cinematic)`: `#F59E0B` (琥珀金，起落幅标记与运镜高亮)
  - `Status-Safe (FinOps Pass)`: `#10B981` (翠绿，余额充足与渲染就绪)
  - `Status-Danger (Breaker)`: `#EF4444` (警示红，熔断阻断与异常)
- **字体与排版**：
  - 代码/参数/金额：`JetBrains Mono`, `Consolas`, monospace (数字等宽展示，防止布局跳动)。
  - UI 文本：`Inter`, `-apple-system`, `PingFang SC`, sans-serif。

## 4. 核心交互工程规范 (Frontend Engineering Specifications)

### 4.1 状态机模型（拒绝布尔状态爆炸）
每个镜头严格遵循有限状态机：
$$\text{State} \in \{\text{DRAFT}, \text{SCRIPT\_SPLIT}, \text{KEYFRAME\_GENERATING}, \text{REVIEW\_PENDING}, \text{INPAINTING\_RUNNING}, \text{KEYFRAMES\_APPROVED}, \text{VIDEO\_SYNTHESIZING}, \text{READY}, \text{FAILED}\}$$

### 4.2 HTML5 Canvas 局部掩码生成引擎
- **笔刷性能**：使用 `requestAnimationFrame` 追踪指针轨迹，支持 5px ~ 80px 动态调节。
- **掩码导出规范**：
  - 导出为标准的 $W \times H$ 单通道 PNG；
  - 涂抹缺陷区域绘制为 `rgba(255, 255, 255, 1.0)`（白色，值为 255）；
  - 保留合格区域绘制为 `rgba(0, 0, 0, 1.0)`（黑色，值为 0）；
  - 客户端即时预览支持半透明红宝石色 (`rgba(239, 68, 68, 0.4)`) 叠加，精准标记缺陷。

### 4.3 透光台模式 (Onion Skinning)
- 前端利用 CSS 硬件加速混合模式 (`mix-blend-mode: normal` + `opacity`)；
- 滑块拖拽实时在 0%（纯起幅）到 100%（纯落幅）之间无缝线性插值，帧率保持 60fps。

### 4.4 事前熔断警报弹窗 (FinOps Blocker Modal)
- 当用户账户余额 $< \text{Cost}_{\text{est}} \times 120\%$ 时，全局拦截「开始合成」及「批量生成」交互；
- 弹窗呈现高对比度警示卡，展示：
  1. 当前可用余额；
  2. 预估安全阈值；
  3. 缺额计算值；
  4. 302.AI 官方充值直达按钮。
